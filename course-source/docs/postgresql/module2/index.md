# Модуль 2. Разработка базы данных на основании ER-диаграммы

Создайте базу данных на основании разработанной ER-диаграммы, используя предпочтительную платформу, на сервере баз данных, который вам предоставлен. Создайте таблицы основных сущностей, атрибуты, отношения и необходимые ограничения. После создания базы данных требуется импортировать данные из файла **«Заказчики.json»**.

## Необходимые приложения

- `Прил_2_ОЗ_КОД 09.02.07-5-2026-М2.rar`

👉 [Приложение к модулю 2](../assets/files/Прил_2_ОЗ_КОД%2009.02.07-5-2026-М2.rar)

## Как проверить результат

1. Создайте таблицы в схеме `app` по [шагам конструктора pgAdmin](example_solution_constuct.md).
2. Сверьте первичные ключи и связи с диаграммой из первого задания.
3. Импортируйте «Заказчики.json» через подготовленный в Excel CSV. В таблице `counterparty` должно быть шесть строк с исходными текстовыми идентификаторами.
4. Выгрузите структуру и данные и восстановите файл в отдельной пустой базе. Откройте таблицу контрагентов в обеих базах.
