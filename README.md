# ДЭ 2026 · Специалист по информационным системам

Подготовка к демонстрационному экзамену по комплекту [09.02.07-5-2026](https://bom.firpo.ru/Public/5510). Базовый уровень включает пять заданий. На выполнение отводится 150 минут, максимальная оценка — 50 баллов.

В учебном маршруте используется Windows Forms с MySQL, MariaDB или PostgreSQL.
