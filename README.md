# ДКИП 2026

Подготовка к демонстрационному экзамену по комплекту [09.02.07-5-2026](https://bom.firpo.ru/Public/5510). Материалы базового уровня находятся в `course-source/`. Путь к другой копии материалов можно указать через `COURSE_SOURCE`. Интерфейс использует шаблон курса `2027-dkip-demo`.

Два стека используют Windows Forms с MySQL / MariaDB или PostgreSQL. Базовый уровень включает пять заданий, 150 минут и 50 баллов. В тренировке открыт официальный образец. В пробном экзамене есть 30 учебных вариантов по образцу 2026 года: собственные исходные данные, пять заданий и непрерывный таймер. Оба стека используют одни и те же варианты. В разделе «Преподавателю» доступна презентация на 113 слайдов с пошаговым разбором всех пяти заданий для Windows Forms и MySQL / MariaDB.

## Запуск

Требуются Node.js, npm и утилиты `unzip` и `bsdtar`. Для постраничного просмотра PDF сборка использует `pdftoppm` при его наличии.

```sh
npm ci
npm run dev
```

Локальный адрес — `http://127.0.0.1:8772/`. Статический результат находится в `site/`. Для проверки готовой сборки используйте `npm run build` и `npm test`.

Исходные книги учебных вариантов лежат в `content/case-workbooks-2026/`. После изменения данных в `content/cases-2026.mjs` обновите их скриптом `scripts/prepare-cases-2026.mjs`, указав каталог с `@oai/artifact-tool` через `DKIP_ARTIFACT_NODE_MODULES`.
